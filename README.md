# Kasu Player v1.1

Retro cassette music player.

Features:
- Previous / Next song
- Rewind / Fast Forward 10 seconds
- Play / Pause
- Animated cassette reels while playing
- Add multiple MP3/audio files
- Playlist
- Full Display screen
- Tap a playlist song to play it

Build:
1. Install Flutter.
2. Open this folder in Android Studio or VS Code.
3. Run: flutter pub get
4. Run: flutter build apk --release
5. APK: build/app/outputs/flutter-apk/app-release.apk
